# From Newton to Kerr

**Hamiltonian Structure, Numerical Fidelity, and Relativistic Orbital Dynamics**

This public repository is being established as the durable version-controlled
foundation of *From Newton to Kerr*, a theory-first computational-physics
project led by Edgar Axel Pérez Flores in collaboration with Naomi Sánchez
Torres.

The Scientific Constitution and Project Governance and Repository Charter have
been ratified. Gate 0B, the repository and collaboration foundation, is
currently in progress.

Production numerical models, scientific validation, and research results are
not yet authorized or claimed. The complete repository foundation will be
introduced through a reviewed pull request after protection of the `main`
branch.
